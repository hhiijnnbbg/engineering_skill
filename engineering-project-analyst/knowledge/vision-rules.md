# 机器视觉工程规则

## 相机

### 参数影响

- 曝光时间 ↑ → 帧率 ↓：曝光是帧率的硬约束
- 增益 ↑ → 噪点 ↑：优先调光源，其次曝光，最后增益
- ROI 减小 → 帧率可提升

### Trigger 模式

- 硬触发：PLC/IO 触发，用于运动拍照，时序可靠
- 软触发：软件发指令，用于调试或低速场景
- 连续模式：仅用于调试图像，生产环境慎用

### SDK 生命周期

```text
初始化 SDK → 枚举设备 → 打开相机 → 注册回调 → 开始取流 → 停止取流 → 关闭相机 → 反初始化
```

规则：

- 顺序不可颠倒，关闭必须先停流再关相机
- 掉线处理：注册掉线回调，掉线后进入重连流程；禁止在回调线程里直接执行重连以外的耗时操作
- SDK 对象为稀缺资源，全局唯一管理，禁止重复 Open

## 镜头

关键参数关系：

- WD（工作距离）：镜头前端到被测物距离
- FOV（视野）：`FOV = 芯片尺寸 × WD / 焦距`
- 焦距 ↑ → FOV ↓，WD 通常 ↑
- 景深：光圈越小（F 值越大）景深越大，但进光量减少

选型顺序：确定 FOV 和 WD → 计算焦距 → 匹配芯片尺寸 → 校核精度（精度 = FOV / 像素数）。

## 光源

| 类型 | 适用 |
|-----|------|
| 环形光 | 通用漫射照明，平面检测 |
| 条形光 | 边缘、长条工件 |
| 背光 | 轮廓、尺寸测量（效果最优） |
| 同轴光 | 高反光平面（镜面、玻璃） |
| 低角度/暗场 | 表面划伤、凹凸缺陷 |

原则：缺陷与背景的对比度靠光源设计解决，不是靠算法硬扛。
